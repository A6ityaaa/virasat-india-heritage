# Virasat Legacy

Build a web app called "VIRASAT" showcasing the Culture and Heritage of India.



Design direction (important): Avoid generic SaaS/AI-generated look — no purple gradients, no centered hero with 3 icon cards, no default sans-serif everywhere. Use a color palette rooted in Indian art: deep saffron, maroon, gold, ivory. Use a distinctive serif or Indian-inspired display font for headings. Design should feel premium and editorial, like a museum or travel magazine site, not a startup template.



Core features:

1. Homepage with our logo, app name, tagline, and a short mission statement about preserving India's heritage

2. Interactive India map divided by state — clickable, opens that state's page

3. Each state page: 2-3 major cities, and for each city — cultural heritage highlights (monuments, festivals, crafts), traditional outfits, local language, and famous food, written as short engaging narrative blurbs, not dry textbook facts

4. Filters on the map to browse by category: Monuments, Food, Festivals, Crafts

5. Make all state/city content editable through an admin view
